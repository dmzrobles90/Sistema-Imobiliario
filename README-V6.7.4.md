# Plataforma Imobiliária V6.7.4 — Ordenação universal de tabelas

- Todos os cabeçalhos de dados das tabelas podem ser clicados para ordenar.
- Primeiro clique: crescente; segundo clique: decrescente.
- Indicadores visuais ↑ / ↓ mostram a ordenação ativa.
- Reconhece texto, números, valores em R$, percentuais e datas em formato brasileiro.
- A ordenação continua aplicada quando a tabela é atualizada/recarregada pelo frontend.
- Colunas de Ação/Ações não são ordenáveis.
- Funciona também em tabelas criadas dinamicamente, como telas/modais carregados depois.
- Não requer alteração de banco de dados ou SQL.
